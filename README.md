## 🎯 Sobre o Projeto

O objetivo deste projeto foi criar uma landing page moderna, rápida e responsiva que sirva como principal canal de captação de clientes para o personal trainer. O site apresenta sua metodologia, benefícios, provas sociais (resultados e depoimentos) e planos de consultoria, com chamadas para ação (CTAs) diretas para o WhatsApp.

---

## ✨ Funcionalidades Principais

* **Design 100% Responsivo:** Totalmente adaptado para uma experiência de usuário perfeita em desktops, tablets e smartphones.
* **Menu de Navegação Fixo:** O header permanece visível durante o scroll, com um efeito de `backdrop-filter` (blur) e links que utilizam `scroll-behavior: smooth`.
* **Menu Mobile (Hamburger):** Menu "hamburger" funcional criado com JavaScript vanilla, que trava o scroll do corpo (`body.nav-open`) quando aberto.
* **Carrossel de Depoimentos:**
    * **Desktop:** Um slider interativo com botões "anterior/próximo" (controlado por JS).
    * **Mobile:** O slider se transforma em um carrossel nativo de *swipe* (arrastar para o lado), melhorando a usabilidade em telas sensíveis ao toque.
* **Scroller Infinito de Resultados:** Uma seção de "Transformações Reais" que utiliza animação CSS (`@keyframes scroll`) para criar um carrossel infinito e automático de imagens.
* **Tipografia e Cores Modernas:** Utilização de Google Fonts (`Russo One` e `Barlow`) e um esquema de cores (preto, branco e amarelo) gerenciado por variáveis CSS (`:root`) para fácil manutenção.
* **Boas Práticas de HTML e CSS:** HTML5 semântico, CSS moderno com Flexbox, Grid, `clamp()` para fontes responsivas, e código JS robusto e modularizado.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído do zero utilizando as seguintes tecnologias:

* **HTML5:** Estrutura semântica e acessível.
* **CSS3:** Estilização moderna (Flexbox, Grid, Variáveis CSS, Animações, Media Queries).
* **JavaScript (Vanilla):** Utilizado para a interatividade do menu mobile e do slider de depoimentos, sem a necessidade de bibliotecas externas.
* **Font Awesome:** Para os ícones sociais e de navegação.
